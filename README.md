# Ananda Marga

## Description

Ananda Marga est une application web développée avec le framework Flask. 
Ce projet a pour objectif de presenter la mission d`Ananda Marga et ces évènements. 
Il s’appuie sur une architecture simple et modulaire pour faciliter le développement et la maintenance.

## Fonctionnalités

- Faire la présentation de la mission Ananda Marga.
   
1. **Ouvrir le projet :**
    ```bash
   cd Projet1-ProgrammationWeb
    ```

2. **Créer un environnement virtuel :**
    ```bash
    python -m venv env
    ```
    Puis activez-le :
    - Sur macOS/Linux :
      ```bash
      source env/bin/activate
      ```
    - Sur Windows :
      ```bash
      env\Scripts\activate
      ```

3. **Installer les dépendances :**
    ```bash
    pip install -r requirements.txt


## Utilisation

Pour lancer l’application en mode développement, utilisez la commande suivante :
```bash
   flask run
 ```
